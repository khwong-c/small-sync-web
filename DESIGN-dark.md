## Brand & Style

This design system translates the weightless, optimistic essence of cloud synchronization into an immersive, luminous dark environment. Tailored for modern developers, independent creators, and agile teams, it strips away harsh, clinical aesthetics in favor of deep atmospheric depth and radiant feedback.

- **Weightless Atmosphere:** Built on deep midnight navy and rich slate tiers rather than void-like absolute black, creating a natural sense of space and cool undertones.
- **Electric Precision:** Luminous electric sky and vivid mint highlights cut through dark surfaces with clarity, ensuring status states, payload schemas, and toggle switches are immediately perceptible.
- **Approachable Modernity:** High-legibility geometric typography balanced with rounded, pill-shaped interactive anchors and frosted, glassmorphic sheen.

## Colors

The dark mode palette uses deep, cool slate tones to establish atmospheric dimension, enriched by high-saturation neon accents that illuminate key interactions.

- **Primary (`#38bdf8` / `#0ea5e9`):** Luminous electric sky blue optimized for dark backgrounds. Applied to primary calls-to-action, key sync badges, focal toggles, and glow halos.
- **Secondary (`#34d399`):** Radiant botanical mint for real-time sync verification, active connections, and affirmative health states.
- **Tertiary (`#fb923c`):** Warm amber-apricot reserved for usage warnings, pending sync queues, alert indicators, and developer telemetry callouts.
- **Neutral Canvas Hierarchy:**
  - `canvas-base` (`#080c14`): Deepest background layer for primary workspace and viewport framing.
  - `surface-subtle` (`#0d1321`): Recessed containers, table structures, and toolbars.
  - `surface-card` (`#131c2e`): Resting cards, panels, and code inspector zones.
  - `surface-elevated` (`#1a253b`): Raised dialogs, dropdowns, and floating command palettes.
- **Text & Stroke Elements:** Pure white headings (`#f8fafc`) provide high visual hierarchy against dark panels, paired with soft mist slate (`#94a3b8`) for continuous body text, and steel slate (`#64748b`) for captions, hints, and borders.

## Typography

The typography couples the geometric friendliness of **Plus Jakarta Sans** for structural headers and actions with the workhorse clarity of **Inter** for descriptions and telemetry metadata. 

- **Display & Headlines:** Keep headline copy tight, clean, and punchy. Negative letter tracking maintains crisp boundaries against dark backgrounds.
- **Labels & Micro-Copy:** Badges and metric identifiers rely on `label-badge` with uppercase styling and wide tracking (`0.08em`) to ensure legibility when overlaid on tinted background chips.
- **Monospace Elements:** Code snippets, client configuration payloads, and cryptographic tokens utilize **JetBrains Mono** to guarantee optical symmetry during code inspections.

## Layout & Spacing

A disciplined 8pt base grid dictates layout density, creating a feeling of spacious clarity without spreading configuration elements too thin.

- **Desktop (1024px+):** 12-column layout bound to a max-width container of 1280px with 1.5rem gutters and 2rem outer margins.
- **Tablet (768px – 1023px):** 8-column layout with 1.25rem gutters and 1.5rem outer canvas padding.
- **Mobile (<768px):** 4-column reflow where cards and multi-column metadata collapse into vertical stacks with 1rem margins.
- **Internal Component Spacing:** Inputs and interactive action bars adhere to `space-sm` (8px) and `space-md` (16px) internal padding, while vertical stacking of module groups takes advantage of `space-lg` (24px) and `space-xl` (40px) separations.

## Elevation & Depth

Depth in this dark mode design system is constructed via tonal layering, translucent glass treatments, and luminous perimeter glow rather than standard drop shadows.

- **Layer 0 (Canvas Base):** Grounded at `#080c14` with a subtle top-centered radial ambient glow (`radial-gradient(circle at 50% 0%, rgba(14, 165, 233, 0.08), transparent 70%)`).
- **Layer 1 (Resting Cards & Panels):** Rendered in `#131c2e` with a low-opacity border (`1px solid rgba(148, 163, 184, 0.12)`). Subtly lit by `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.5)`.
- **Layer 2 (Floating Modals, Flyouts & Menus):** Backdrop frosted (`backdrop-filter: blur(16px)`), filled with `rgba(26, 37, 59, 0.85)` and framed in an electric hairline border (`rgba(56, 189, 248, 0.22)`). Shadow footprint: `0 20px 35px -10px rgba(0, 0, 0, 0.7), 0 0 15px 0 rgba(56, 189, 248, 0.05)`.
- **Active State Highlights:** Hovered components or focused input wrappers radiate a luminous sky glow (`box-shadow: 0 0 0 1px #38bdf8, 0 0 16px -2px rgba(56, 189, 248, 0.35)`).

## Shapes

The geometry balances soft, protective container curves with full pill-shaped controls for an approachable yet organized visual hierarchy.

- **Containers & Panels:** Modals, cards, and data surfaces use `rounded-lg` (1rem / 16px) or `rounded-xl` (1.5rem / 24px) corners, eliminating aggressive angularity.
- **Controls & Indicators:** Interactive buttons, search chips, and live sync badges are pill-shaped (`9999px`) to maintain the signature soft pop feel.
- **Form Inputs & Code Insets:** Styled with standard `rounded-lg` (0.75rem / 12px) radii for proportional alignment with internal text baselines.

## Components

### Buttons
- **Primary:** Full pill (`rounded-full`), solid `#38bdf8` background with `#080c14` bold text. On hover, background shifts to `#0ea5e9` with an electric glow (`box-shadow: 0 0 20px rgba(56, 189, 248, 0.4)`). Active clicks compress subtly to `0.98` scale.
- **Secondary / Soft Pop:** Pill contour, semi-transparent teal-mint background (`rgba(52, 211, 153, 0.12)`), text in `#34d399`, and border framed in `rgba(52, 211, 153, 0.3)`.
- **Ghost:** Full pill, transparent background, text in `#94a3b8`. Hover transitions to `#f8fafc` text with a subtle background wash (`rgba(255, 255, 255, 0.05)`).

### Badges & Status Chips
- Height: 24px–28px, `rounded-full` contour with `label-badge` uppercase typography.
- **Live Sync Active:** Background `rgba(52, 211, 153, 0.1)`, border `rgba(52, 211, 153, 0.3)`, text `#34d399`, with a pulsing 6px mint beacon.
- **Syncing in Progress:** Background `rgba(56, 189, 248, 0.1)`, border `rgba(56, 189, 248, 0.3)`, text `#38bdf8`, with an inline spinning indicator.
- **Degraded / Outdated:** Background `rgba(251, 146, 60, 0.1)`, border `rgba(251, 146, 60, 0.3)`, text `#fb923c`.

### Cards & Configuration Blocks
- Built on `#131c2e` with a delicate 1px border (`rgba(148, 163, 184, 0.12)`).
- Section headers carry clear division lines using `rgba(148, 163, 184, 0.08)`.
- Inner code inspector wells utilize `#0d1321` with recessed shadows to differentiate operational controls from raw payload data.

### Input Fields & Secret Keys
- Base containers use `#0d1321` fill with a `1px` border in `rgba(148, 163, 184, 0.2)`. Placeholder copy sits at `#64748b`.
- On focus, border transitions to `#38bdf8` with an active halo (`box-shadow: 0 0 0 3px rgba(56, 189, 248, 0.2)`).
- Utility actions (copy key, regenerate token, view schema) are housed inside miniature pill buttons aligned right within the input perimeter.

### Checkboxes, Switches & Radio Controls
- **Toggle Switches:** Track measures 44px by 24px with a rounded pill form. Inactive track is `#1a253b`; active track is `#38bdf8`. The thumb is pure `#f8fafc` with a high-contrast dark drop shadow.
- **Checkboxes:** Standard `rounded-md` (6px) base with `#0d1321` resting fill. Checked state sets background to `#34d399` with a `#080c14` check icon.

### Sync Event Timeline / Logs
- A dark-optimized timeline featuring a luminous sky-blue thread line (`rgba(56, 189, 248, 0.25)`). Event nodes pulse with radial rings indicating device heartbeats and successful payload handshakes.
